# 新人教育カリキュラム(製造部)

製造部 教育担当
2026年4月版

## 基本方針

独り立ち(単独での機械操作と品質判断)までの標準期間は**6ヶ月**を目安とする。
習熟の速さには個人差があるため、期間ではなく到達度で判断する。
判断は所属課長が行い、工場長へ報告する。

## 1ヶ月目:安全教育と職場理解

- 安全衛生教育(法定)8時間
- 保護具の着用、危険予知訓練(KYT)
- 5S活動、工場内の動線とルール
- 各工程の見学と製品知識
- 到達目標:一人で工場内を安全に移動でき、危険箇所を指摘できる

この期間は機械の単独操作を一切行わない。

## 2ヶ月目:図面読解と測定

- 三面図の読み方、寸法公差と幾何公差
- 表面粗さ記号
- ノギス・マイクロメータ・ハイトゲージの使用法
- 測定値の記録と判定
- 到達目標:図面から加工部位と公差を読み取り、完成品を測定して合否判定できる

## 3〜4ヶ月目:実機操作(指導者同伴)

- 材料のセット、原点出し
- プログラムの呼び出しと単一ブロック運転
- 工具交換、切削条件の意味
- 段取り替えの補助
- 到達目標:指導者の立会いのもと、定常品の加工を通しで行える

## 5〜6ヶ月目:単独作業の準備

- 段取り替えを単独で実施
- 不良発生時の一次判断と報告
- 日常点検の実施と記録
- 到達目標:定常品について、段取りから完成品検査まで単独で完了できる

## 独り立ちの判定基準

以下すべてを満たすこと。

1. 定常品3品番以上で、段取りから検査まで単独完了の実績がある
2. 日常点検を1ヶ月以上、記録漏れなく実施している
3. 不良を発見した際に自己判断で止めて報告した実績がある
4. 課長による口頭確認(安全・品質・報告の3項目)に合格している

## 独り立ち後のフォロー

独り立ち後3ヶ月間は、週1回の振り返り面談を課長が実施する。
