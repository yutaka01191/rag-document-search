# RAGデモ用サンプル文書セット

株式会社ミナミ精密工業(架空の中小製造業・従業員45名・金属加工)を想定した社内文書10本。
**すべて架空の内容で、実在の企業・人物・取引とは一切関係ありません。**

RAGデモの動作確認と商談時のデモンストレーション用に作成。以下の性質を持たせている。

- 文書種別がばらけている(規則・マニュアル・議事録・手順書・一覧・FAQ)ので、
  Text Splitterがそれぞれ違う構造をどう切るかを確認できる
- 検索で引ける具体的な数値・固有名詞・日付を各文書に埋め込んでいる
- 複数文書にまたがる質問("2号機の異音はどうなった?")が成立するよう、
  議事録2本を時系列で繋げている

## 動作確認に使える質問例

- 有給休暇は何日前までに申請すればいいですか
- 経費精算の締切はいつですか
- 接待交際費で事前承認が必要な金額はいくらからですか
- NCフライス盤2号機の異音は解決しましたか
- 4月と5月で不良率はどう変わりましたか
- クーラント液の交換頻度を教えてください
- A社への納品ルールを教えてください
- 見積の加工費の時間チャージはいくらですか
- 新人が独り立ちするまでの目安期間は
- クレームが来たら何時間以内に報告書を出す必要がありますか
