# 経費精算マニュアル

管理部 総務課
2026年3月版

## 1. 提出期限

経費精算書は**毎月5日まで**に、前月分をまとめて管理部へ提出すること。
5日が休日の場合は翌営業日とする。期限を過ぎた分は翌月の精算に回るため、
立替から支払いまで最長で2ヶ月かかる点に注意すること。

## 2. 交通費

実費精算とする。電車・バスは領収書不要だが、ICカードの利用履歴を印刷して添付すること。
タクシーの利用は原則として認めないが、次の場合は事前承認により認める。

- 公共交通機関が利用できない時間帯の移動
- 重量物・精密部品の運搬を伴う移動
- 顧客同行

自家用車を業務利用した場合のガソリン代は、走行距離1kmあたり15円で計算する。

## 3. 接待交際費

**1件5,000円を超える接待交際費は、支出前に部長の事前承認が必要**である。
承認は社内稟議システムで申請し、参加者の氏名・会社名・目的を記載すること。
事後申請は原則として認めない。

## 4. 立替払いの上限

個人の立替払いは1件あたり**3万円**を上限とする。
これを超える支出が見込まれる場合は、管理部へ事前に連絡し、
会社振込または法人カードでの決済に切り替えること。

## 5. 領収書の取り扱い

領収書は原本を糊付けして提出する。宛名は「株式会社ミナミ精密工業」とし、
「上様」での受領は認めない。感熱紙の領収書は退色するため、
コピーを添付のうえ原本も同封すること。

## 6. よくある差戻し理由

- 宛名が個人名になっている
- ICカード履歴が添付されていない
- 接待交際費の参加者が記載されていない
- 提出期限を過ぎている
