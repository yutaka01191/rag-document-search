# 生産会議 議事録(2026年4月度)

日時:2026年4月14日(火)15:00〜16:20
場所:本社2階 会議室A
出席:工場長 佐藤、製造1課 田中、製造2課 鈴木、品質保証 高橋、営業 渡辺
記録:製造1課 田中

## 1. 前月実績の報告

3月度の生産数量は計画比98%で着地。受注残の消化は順調。
一方、**不良率は1.8%**となり、社内目標の1.5%を上回った。
主要因は材料ロットの硬度ばらつきによる寸法不良。品質保証より、
仕入先へ硬度データの提出を依頼済みとの報告があった。

## 2. A社向け納期遅延について

営業 渡辺より、A社向けロットの納期が3日遅延した件について報告。
原因は段取り替えの集中による稼働待ちで、設備の問題ではない。
対策として、A社向けの品番は毎週火曜・木曜にまとめて流す運用に変更する。
渡辺よりA社へは既に説明済み、了承を得ている。

## 3. NCフライス盤2号機の異音

製造2課 鈴木より、**NCフライス盤2号機の主軸から異音**が発生しているとの報告。
3月下旬から断続的に発生しており、現時点で加工精度への影響は確認されていない。
メーカーに点検を依頼し、4月中に一次診断を受ける予定。
主軸ベアリングの劣化が疑われるとのこと。
異音が大きくなった場合は即時停止し、1号機・3号機へ振り替える。

## 4. 残業時間

3月の平均残業時間は月28時間。36協定の上限に対して余裕はあるが、
製造2課のみ月38時間と高い。2号機の不調による段取り増が影響している。
